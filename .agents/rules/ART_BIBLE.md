MASTER ART DIRECTION

All visual assets in this game MUST belong to the same visual universe as the approved master reference image.

MASTER STYLE:
Cute Retro Anime Cartoon × Premium Fashion Illustration.

VISUAL DNA:
- Polished 2D hand-drawn game illustration
- Clean confident rounded outlines
- Soft cel shading
- Subtle highlights
- Pastel candy color palette
- Pink, lavender, cream, peach and soft blue
- Cute feminine proportions
- Rounded and readable silhouettes
- Expressive anime-inspired faces
- Fashion-forward shapes
- Playful 90s cartoon influence
- Premium mobile game finish
- Strong silhouette readability
- Consistent visual hierarchy

CONSISTENCY RULE:
Every new character, outfit, furniture piece, shop prop, item, decoration and UI illustration must look as if it was designed by the SAME professional art team for the SAME game.

Do not introduce unrelated art styles.

FORBIDDEN:
- Photorealism
- 3D rendering
- Generic vector illustration
- Flat corporate UI graphics
- Realistic product photography
- Excessive gradients
- Random line weights
- Excessive texture
- Emoji
- Unicode symbols used as icons
- Decorative symbols such as ✦ ✧ ★ ☆ ✨
- Unrelated anime styles
- Unrelated cartoon styles

When creating a new asset, prioritize STYLE CONSISTENCY over unnecessary detail.
